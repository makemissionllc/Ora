# Ora ideas

Ideas for custom features. Nothing here is built yet. Each idea moves to PROGRESS.md (*In progress*) when work starts.

## Priority 1

1. **Site tweaks**: per-site changes to how a page looks or behaves (for example text size, desktop or mobile layout, or a dark look), saved for that site only.
2. **Element zapper**: tap an element on a page to hide it, so clutter such as banners or sticky bars goes away for that page.
3. **Command bar**: one field that runs actions by typing, such as opening a tab, finding a page, or changing a setting.
4. **Profile rules**: rules that pick a profile by site, so a site always opens in the right profile.
