Ora Browser is an open-source Chromium-based browser for Android with desktop-style extension support.

Ora supports desktop-style extensions, including Manifest V2 extensions, from the Chrome Web Store, Opera Add-ons, and Microsoft Edge Add-ons. You can also install local CRX or ZIP packages through the bundled companion extension, or load an unpacked extension for development from chrome://extensions.

Open chrome://chrome-urls for browser debug pages and chrome://flags for experiments. WebRTC IP handling is available in Settings under Privacy and security.

Ora Browser is distributed under GPL-2.0. Source code and build information: https://github.com/makemissionllc/Ora
